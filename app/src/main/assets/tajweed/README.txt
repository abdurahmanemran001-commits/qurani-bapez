Tajweed Color Mushaf data
=========================

This optional Color Mushaf mode downloads the MIT-licensed
TheHolyQuranJSONFormat Tajweed dataset during the Android build:

https://github.com/CheeseWithSauce/TheHolyQuranJSONFormat

The dataset provides Uthmani Quran text with Tajweed HTML markup.
The app renders only the requested page's ayahs and keeps the
existing Android audio/timing/highlight pipeline unchanged.

The bundled Noorehira font is copied from the existing project
Naskh asset. The font source states that it is free to use.

This data is used only as an integrated app asset; it is not exposed
as a separate API or download.

The Tajweed dataset repository is MIT licensed.
