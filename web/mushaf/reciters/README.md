# Reciter photos
Put a square-ish JPG named `<key>.jpg` here, e.g. `ghamdi.jpg`, `alafasy.jpg`, `sudais.jpg`, `shuraym.jpg`, `husary.jpg`, `minshawi.jpg`, `abdulbasit.jpg`.
The reader shows the photo automatically; without a file it shows a coloured initial instead.
Use only photos you have the right to use.
